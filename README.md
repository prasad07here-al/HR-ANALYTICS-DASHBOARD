# HR Analytics Dashboard – Power BI

An interactive **Power BI dashboard** developed to analyze employee data and understand key HR and workforce trends.

## 📊 Project Overview

This project analyzes employee data to provide insights into workforce composition, employee performance, and important HR metrics through interactive visualizations.

## 🛠️ Tools Used

- Power BI
- Power Query
- DAX
- Data Visualization

## 🔍 Key Analysis

- Employee Demographics
- Department-wise Analysis
- Employee Performance
- Workforce Trends
- Attrition Analysis
- Key HR Metrics

## 📈 Dashboard Features

- Interactive KPI cards
- Dynamic charts
- Slicers and filters
- Department and employee analysis
- User-friendly dashboard

## 💡 Key Outcome

The dashboard transforms employee data into meaningful insights to support HR analysis and data-driven workforce decisions.
